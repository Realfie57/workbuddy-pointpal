# 收件人请看这里（Quick start）

**WorkBuddy PointPal**——一个贴在桌面上的小挂件：角色举着一块黑屏平板，平板上实时显示你的 **WorkBuddy 积分余额**。  
积分每下降 **1 分**（步长可调），角色就红闪 + 震动 + 播放打击音效，头顶飘出 `-1`  
（0.2 秒一次，飘出的数字会串成一条）。

美术形象与动画和 DSH 余额桌宠完全相同，数据源换成了 WorkBuddy。

## 怎么用

### 方式 A：Setup 安装包（推荐）

1. 双击 **`WorkBuddy PointPal Setup.exe`**，跟着向导走：
   选**安装文件夹**（默认在当前用户的 Programs 下，无需管理员权限；
   选 Program Files 等系统目录会在点「安装」时弹 UAC 授权，自动按全机安装）→
   勾选**桌面/开始菜单快捷方式**（开始菜单里会带卸载入口）→ 可选**开机自动运行** →
   最下面还可勾选**「WorkBuddy & PointPal」桌面快捷方式**（默认关）——
   一次双击同时启动 WorkBuddy 和桌宠；**不勾也会**在安装目录里留一份
   `WorkBuddy & PointPal.vbs` 备用 → 完成。
   （桌面快捷方式用的是 WorkBuddy 风格的专属图标，不是桌宠自己的图标，方便一眼区分；
   也可以像普通应用一样**右键固定到任务栏**。）
2. 第一次启动需要登录凭证（获取方法见方式 C 的第 3 步，各方式通用）。
   凭证是浏览器会话，**过一段时间会过期**；过期后屏幕亮红点，重新粘贴一次即可。
3. 想卸载：开始菜单「WorkBuddy PointPal → 卸载」，或系统「设置 → 应用」里卸载；
   你的凭证和设置默认会保留（卸载时会问你是否一并删除）。

> **一台电脑只装一份**：安装程序启动时若发现本机已装过，
> 会提示你先卸载原有软件——点确定就自动跑完卸载再继续安装，点取消则本次安装终止。
> （便携 exe 不写注册表，不会被检测到，可以和安装版共存。）


> exe 未签名，SmartScreen 首次可能提示，点「更多信息 → 仍要运行」即可。

### 方式 B：便携 exe（免安装）

把 **`WorkBuddy PointPal.exe`** 拷到任意位置，**双击运行**（无需安装任何东西，Win10/11 即可）。
首次运行会自动把美术/音效等资源解压到 `%LOCALAPPDATA%\WorkBuddy PointPal\`，你的设置和凭证也存在那里。
挂件出现在**屏幕左下角**，默认 **8cm 高**。
开机自启：`Win + R` 输入 `shell:startup`，把 exe 的快捷方式丢进去。

### 方式 C：PowerShell 脚本版（整个文件夹）

1. **解压到任意目录**（路径里有中文也没关系，但请不要放在只读位置）。
2. 双击 **`启动 WorkBuddy PointPal.vbs`**。
3. **第一次启动需要登录凭证**（WorkBuddy 没有公开 API Key，从浏览器复制一次即可）：
   1. 浏览器打开 [www.workbuddy.cn](https://www.workbuddy.cn) 并登录；
   2. 按 `F12` 打开开发者工具，切到 **Network（网络）** 标签页；
   3. 选择查看 **Doc（文档）** 类型的请求，**刷新页面**；
   4. 找到 `www.workbuddy.cn`，**右键** →「复制」→「**以 cURL 格式复制**」（bash）；
   5. 回到桌宠：右键 →「设置登录凭证」，在弹出的**多行输入框**里整段粘贴（`Ctrl+V`）即可。
      程序会自动从 cURL 里提取 Cookie 和 User-Agent——粘贴框上方就写着这件事，
      **必须整段 cURL 一起粘**（网关把登录会话绑定在 UA 上，只粘 Cookie 不带 UA 必定 401）。
      **第一次启动时程序会自动弹这个输入框**，不用自己找菜单；框左下角还有个
      「**如何获取凭证...**」按钮，忘了上面几步就点它。
   不想填就取消，挂件会先离线待着（屏幕显示 `--`，右上角亮红点）——之后随时右键补上。  
   凭证过期（或 Edge 大版本升级导致 UA 变化）后屏幕亮红点，重新复制粘贴一次就行，
   输入框最下面那行也提醒了这件事。
4. 挂件出现在**屏幕左下角**，默认 **8cm 高**（宽度随角色造型自动适配）。

## 常用操作

| 操作     | 效果                                                         |
| ------ | ---------------------------------------------------------- |
| 左键按住拖动 | 移动；**松手后自动吸附到所在半屏的底角**：拖到右半边松手 → 吸附**右下角**，同时角色镜像翻转、脸朝左；拖回左半边 → 回到左下角 |
| 右键     | 菜单：立即刷新积分 / 测试一次扣费 / 演示连续扣费 / 尺寸 / 扣费步长 / **扣费字号** / 屏幕标签 / **角色** / **受击音效** / 设置凭证（框内左下角有「如何获取凭证...」）/ **关于…** / 退出 |
| 双击托盘图标 | 手动触发一次扣费动画                                                 |

**角色**：右键 →「角色」，可在大肥鱼（默认）、Claude、Gemini、GPT 之间切换，
每个角色还有**完整版**（全身带尾，画幅更宽）和**去尾版**（近景方形）两种造型，共 8 个选项。  
**扣费字号**：头顶飘出的 `-1` 数字大小，1~4 倍 preset 或自定义 0.5~10 倍。  
**受击音效**：勾选开、取消关，立即生效。  
**关于**：右键 →「关于…」（在「退出」上一行）可看到当前**版本号**和数据目录；
「关于」框左下角还有「**检查更新**」——点它会去 GitHub 查有没有新版本，有新版本就给你一个
「打开下载页面」按钮。**只提示，不自动更新**，不点就完全没有网络请求。
以上选择和左右侧位置都会记住，下次启动自动恢复。

**立即刷新积分** = 平板立刻对齐到最新余额（不补播动画）。  
后台每 5 秒自动查一次；余额一有变化就**一分一分地扣**，每次都有完整的动画 + 音效。

想看连续扣费的效果：右键 →「演示连续扣费」→ 选 `-10` 之类，  
就会以 0.2 秒一次连着扣 10 次给你看（纯演示，不影响真实数据）。

## 遇到问题

**双击 vbs 没反应 / 杀软报警**  
这个挂件用 Windows 自带的 PowerShell 写界面，`.vbs` 启动器只是用来隐藏黑框，偶尔会被杀软误报。  
改成双击 **`启动（调试窗口）.cmd`**，它会保留一个黑窗口把错误显示出来。  
（exe 版没有这个问题；若 exe 双击没反应，在 cmd 里运行 `"WorkBuddy PointPal.exe"`，
或看 `%LOCALAPPDATA%\WorkBuddy PointPal\error.log`。）

**屏幕一直显示 `--`**  
积分没取到。exe 版看 `%LOCALAPPDATA%\WorkBuddy PointPal\pet.log`，脚本版看同目录的 `pet.log`。

- 出现 `HTTP 401` → 凭证过期或不对，右键 →「设置登录凭证」重新粘贴。
- 出现 `cannot parse response` → 接口返回结构变了，把 `pet.log` 里的内容发给作者。
- 出现 `node not found` → 极少见，.NET 通道被系统拦住且没装 Node.js；装一个 LTS 版 Node 即可。

**接口报 401 但 Token 明明没填错**  
有些请求还需要 `X-User-Id` 头。在同一个请求的**请求头**里把 `X-User-Id` 的值也复制下来，  
按 `uid:Token` 的形式一起粘贴（冒号分隔）。

**卡顿 / 托盘图标消失**  
右键 →「退出」，再重新启动一次即可。

**重复启动不会有第二个挂件**  
桌宠是单实例的：已经有一个在跑时，再双击快捷方式（无论走「WorkBuddy & PointPal」还是应用自己的快捷方式），第二个进程会**自动退出**，并在托盘弹一条「桌宠已经在运行了」的提示，不会叠出两个。

## 关于

这是一个**独立的桌面小程序**（不是 WorkBuddy 插件）：它自己是一个进程，  
只读取同目录 `token.txt` 里你粘贴的凭证，其余和 WorkBuddy 客户端没有任何耦合，  
WorkBuddy 关掉它也照常运行。

它**不联网上传任何数据**，只访问 WorkBuddy 官方的积分查询接口  
（`POST www.workbuddy.cn/billing/meter/get-user-resource-summary`）。

本项目基于开源项目 [DSH 余额桌宠](https://github.com/VKmich16/VK-1)（Windows 原版）改编，  
美术形象与动画架构沿用原作，感谢原作者。

更多细节看 `说明文档.md`。
